# Nolla AI — российская AI-платформа для творчества

Бот (aiogram 3) + Mini App (React + TypeScript) + FastAPI на общей базе SQLite. Интерфейс и админ-центр — на русском. Стиль Mini App: чёрный фон `#000`, белый текст, оранжевый акцент `#FF6A00`. Админ-центр: светлый фон, чёрный текст, тот же оранжевый.

## Что есть

**Mini App** (на компьютере — боковое меню, на телефоне — нижнее: Главная · История · **+** · Профиль · Ещё; круглая «+» по центру открывает быстрый выбор: изображение, видео, аудио, эффекты). Шапка и нижнее меню зафиксированы, прокручивается только содержимое; на телефоне «Стоимость» и «Создать» закреплены над меню.

| Раздел | Что внутри |
|---|---|
| Главная | приветствие и три кнопки: Создать фото · Создать видео · Посмотреть идеи. Ниже — «Что умеет Nolla AI» (модели и разделы), популярные идеи, что умеет Seedance 2.5, фотосессии, тренды, модели и приглашение друга |
| Идеи | витрина из кода: только снимки 9:16 без подписей. На телефоне — нажал и повторил со своим фото; на компьютере подпись и цена появляются при наведении. Сердечко добавляет в избранное, есть вкладка «Избранное» |
| Создать | редактор: модель, соотношение сторон и «Все параметры» (разрешение (480p/720p/1080p для видео), количество, качество, стиль, длительность, зерно, «чего не должно быть») |
| Модели | изображения: Nano Banana 2, Nano Banana 2.1, Nano Banana 2 Lite; видео: Seedance 2.5, Seedance 2.0. Остальные модели из каталога скрыты (не удалены) — включаются в админке |
| Эффекты | 16 инструментов: Раскадровка (9 кадров с перегенерацией кадра), 9 ракурсов, Виртуальная примерка, Улучшение кожи, Оживить фото и другие |
| Тренды, Фотосессии | готовые образы по 6 и 13 категориям: загрузили фото — получили серию |
| Аватары | мастер: фото (3–25) → согласие → создание; сцены для аватара |
| Промпты | библиотека по 13 категориям: копировать или создать сразу |
| Маркетинг | инструменты и шаблоны: реклама, фото товара, карточки для маркетплейсов, соцсети, UGC |
| Мои генерации | фильтры Все · Фото · Видео · Избранное; превью, тип, дата, модель, стоимость, статус; действия: открыть, скачать, создать заново, в избранное, удалить |
| Профиль | аватар, имя, username, баланс, работы, потрачено, дата регистрации и кнопка «Настройки» |
| Настройки | аккаунт, язык, баланс и финансы, уведомления, безопасность, о приложении |
| Баланс | токены, пакеты СТАРТОВЫЙ / ПРО / СОЗДАТЕЛЬ / СТУДИЯ, демо-оплата |
| Интеграции | MCP-сервер для ChatGPT, Claude, Cursor и Codex; личные токены доступа |

## Витрина «Идеи» — редактируется в коде

Файл: **`app/showcase.py`**. Админка витриной не управляет.

```python
SHOWCASE = [
    {
        "slug": "idea-night-shoot",            # латиницей, уникально
        "title": "Ночная фотосессия",
        "description": "Неон, отражения и город после дождя.",
        "category": "lifestyle",               # код из CATEGORIES в этом же файле
        "kind": "photo",                       # photo | video | audio
        "prompt": "Night photoshoot in a neon-lit city street…",
        "model": "Nano Banana 2",              # название модели или image-default / video-default / audio-default
        "price": 14,                           # 0 — взять цену модели
        "image": "/showcase/night.jpg",        # файл из webapp/public/showcase/, можно пусто
        "needs": ["person"],                   # что прислать: person | photo | product | [] — ничего
        "featured": True,                      # «Рекомендуем»: выше остальных
    },
]
```

* **Картинка или видео:** положите файл в `webapp/public/showcase/` и укажите путь — `"/showcase/имя.jpg"` или `"/showcase/имя.mp4"`.
* **Раздел:** `"section": "idea"` (по умолчанию) · `"trend"` · `"photoshoot"` · `"effect"` · `"marketing"`. В «Идеях» показываются только карточки с `kind: "photo"`; видео кладите в тренды.
* **Новая категория:** допишите пару `("код", "НАЗВАНИЕ")` в `CATEGORIES` — появится вкладка в разделе «Идеи».
* **Скрыть, не удаляя:** `"hidden": True`. Убрали карточку из файла — она скроется сама, история заказов сохранится.
* **Кнопка «Попробовать»** появляется у карточки сама: открывает генератор с этим промптом, моделью и ценой.
* Изменения применяются при перезапуске сервера (`app/services/showcase_sync.py` переносит файл в базу по `slug`).

**Кнопка «+»** стоит в шапке и ничего не перекрывает. Нажатие открывает компактное меню: фото, видео, аудио (и ссылку на эффекты) — на компьютере раскрывается под кнопкой, на телефоне выезжает снизу. На компьютере та же кнопка продублирована в боковом меню.

**Обложки без своей картинки.** Если у карточки нет `image`, подставится файл из папки `data/media/previews` — туда можно просто складывать фото **и видео** (jpg, png, webp, mp4, webm, mov), они подхватятся сами. Нет и их — будет нейтральная плашка. Все карточки везде в формате 9:16, цветные, ряды ровные.

Ещё: глобальный поиск (Ctrl/Cmd + K), онбординг «Добро пожаловать.», кнопки «Что хотите сделать дальше?» после результата (изменить, улучшить, оживить, создать видео/рекламу/фотосессию, использовать как референс, вариация), этапы генерации «В очереди → Создаётся → Обрабатывается → Почти готово → Готово» без выдуманных процентов.

**Бот — такой же интерфейс Nolla AI, как и приложение.** В нём можно создавать всё то же самое:

* Меню: 📷 Создать фото · 🎬 Создать видео · 💡 Посмотреть идеи · 🖼 Мои генерации · 🚀 Открыть Nolla AI. Другого меню в боте нет: старые экраны («категории → образ → пришлите фото», список разделов) удалены.
* Шаги короткие: описание → модель → «Стоимость: N токенов» → создание. На первом шаге бот объясняет оба способа: можно просто написать текстом, а можно прислать своё фото и сказать, что с ним сделать (для видео — сделать ролик из присланного снимка).
* Можно просто написать словами: «создай фото девушки в чёрном костюме на фоне ночного города», «оживи это фото» — бот сам поймёт, что нужно.
* Бот помнит контекст: после «создай фото города» на «теперь сделай из него видео» он возьмёт эту картинку как исходник.
* Можно прислать фото — бот предложит изменить его, сделать видео или применить эффект. Понимает и просьбы вроде «замени фон», «сделай кинематографичнее», «9 ракурсов».
* Под готовой работой — кнопки: Скачать · Создать заново · Изменить · Вариация · Сделать видео (у видео и аудио — свои).
* Команды: `/start`, `/create`, `/profile`, `/history`, `/settings`.

**Приглашение друга.** Ссылка вида `?start=ref_<ID>` уже была; теперь за каждого друга пригласившему начисляются токены — один раз, когда друг впервые входит. Размер бонуса: «Админка → Настройки → Токенов за приглашённого друга» (по умолчанию 20, 0 — выключено). Блок со ссылкой и счётчиком — внизу главной.

**Канал с идеями.** Если в «Админка → Настройки» заполнить «Канал с идеями и промптами», кнопка «💡 Посмотреть идеи» в боте будет вести туда. Пусто — бот покажет идеи прямо в чате.

**Проверка версии бота.** Команда `/version` отвечает меткой сборки и первой строкой приветствия. Если метка не та, что вы залили, — отвечает старый процесс бота (обычно параллельно живёт прошлый деплой). Та же метка видна в «Админка → Система».

**Единая система.** Бот, приложение и админка работают через один API и одну базу: пользователь из бота сразу виден в админке, его генерации попадают и в «Мои генерации», и в статистику, баланс токенов общий. В админке есть отдельный блок «Бот»: пользователи, генерации по типам, ошибки и последняя активность. Параметры запуска: `?start=ref_<ID>` (реферал), `?start=src_<источник>_<кампания>_<материал>` (реклама).

**Админ-центр** (Профиль → Админ-центр) — только управление проектом, без редакторов контента:

| Раздел | Что внутри |
|---|---|
| Дашборд | пользователи (всего, сегодня, 7 и 30 дней, активные), генерации (всего, сегодня, неделя, месяц, по типам), токены (потрачено всего/сегодня/за месяц, куплено, остаток), ошибки генерации и сервера, последние ошибки и последние действия с моделью и статусом |
| Пользователи | ID, имя, username, регистрация, последняя активность, баланс, потрачено, генерации, фото/видео/аудио, откуда пришёл (Бот / Mini App), статус; поиск, фильтры, сортировка по клику на заголовок, пагинация, карточка пользователя |
| Генерации | все работы: пользователь, тип, модель, дата, статус, стоимость |
| Транзакции | пополнения, операции с токенами, выручка |
| Ошибки | ошибки генерации и сервера |
| Настройки | пакеты токенов, приветственный бонус, поддержка, экспорт CSV |
| Система | состояние бота, базы, AI, очереди; предупреждает, если база не на постоянном томе |

Все числа считаются из базы: нет данных — будет ноль, а не выдуманное значение.

**Аудио выключено.** Раздел озвучки убран из приложения и из бота: модель скрыта, вкладки и фильтры не показываются. Код остался на месте — если решите вернуть, достаточно включить аудио-модель в админке.

## Архитектура

```
Интерфейс → API (FastAPI) → Сервис генерации → Маршрутизатор → Провайдер
```

* `app/services/generation.py` — сервис генерации: списание токенов, этапы, возврат при ошибке.
* `app/ai/registry.py` — маршрутизатор: по ключу модели выбирает провайдера.
* `app/ai/mock.py` — **демо-провайдеры**: нейтральные серые изображения, раскадровка, ракурсы, примерка, короткий GIF-«видеоролик», WAV-мелодия. Каждый результат помечен «ДЕМО · НЕ НАСТОЯЩАЯ ГЕНЕРАЦИЯ».
* `app/ai/external.py` — шаблоны реальных провайдеров (`IMAGE_API_KEY`, `VIDEO_API_KEY`, `SEEDANCE_API_KEY`, `AUDIO_API_KEY`). Ключи — только из переменных окружения.

## Обновление

Распакуйте архив поверх папки проекта (`.env` и `data/` в нём нет), затем в PowerShell из папки проекта:

```
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\update.ps1
python -m app.main
```

Скрипт удалит устаревшие экраны, поставит зависимости и соберёт Mini App. База обновится сама при запуске: добавятся таблицы `avatars` и `api_tokens`, новые поля, тип «аудио» (таблицы пересобираются без потери данных), новый каталог и пакеты токенов. Старые пакеты скрываются, но не удаляются.

Новые необязательные переменные: `AUDIO_API_KEY`, `DEMO_DELAY` (пауза этапов демо, секунд), `WELCOME_BONUS` (приветственный бонус, применяется один раз; дальше — в админке).

## Интеграции (MCP)

Адрес: `https://<ваш-домен>/mcp`, заголовок `Authorization: Bearer <токен>`. Токен создаётся в «Профиль → Интеграции» и показывается один раз. Инструменты: `create_image`, `create_video`, `create_audio`, `edit_image`, `get_generation_status`, `get_balance`, `get_history`.

## Тесты

`python -m unittest discover -s tests -t .` — 194 теста, включая 13 сквозных тестов бота (создание фото, видео и аудио, понимание обычных сообщений, контекст, синхронизация с админкой) (3 теста HTTP-слоя пропускаются, пока не установлен FastAPI).
