# Nolla AI — AI-студия внутри Telegram

Бот (aiogram 3) + Mini App (React + TypeScript) на общей базе SQLite. Интерфейс и админ-центр — на русском. Стиль: светлый фон `#F7F7F5`, белые карточки, чёрный `#111111`, оранжевый `#FF6A00`.

## Что есть

**Mini App:** Главная (лендинг) | Создать | **+** | История | Профиль.
* **Главная** — hero, вход через Telegram, «Что умеет», AI-модели, «Не знаете, какую выбрать?», «Сейчас в тренде», «Что уже создают», «Как это работает», токены и пакеты, способы оплаты, «Почему Nolla AI», «О Nolla AI», FAQ, финальный призыв. Всё содержимое берётся из базы и редактируется в админке; пустые блоки не показываются.
* **Создать** — витрина категорий и стилей; **+** — быстрый запуск Фото/Видео.
* **Генератор** — фото необязательно, описание до 500 символов, быстрые стили, выбор модели, количество вариантов, формат, качество, освещение, камера, стоимость в токенах до запуска.
* **Токены** — баланс всегда сверху, «Мои токены» (куплено, потрачено, возвращено, бонусные, история), «Купить токены» (пакеты → способ оплаты).
* **Регистрация** — только через Telegram, без паролей и почты; стартовый бонус токенов включается в админке (по умолчанию выключен).

**Бот:** `/start`, `/create`, `/profile`, `/history`, `/settings`, свободное описание текстом, оплата Stars. Параметры запуска: `?start=ref_<ID>` (реферал), `?start=src_<источник>_<кампания>_<материал>` (реклама).

**Админ-центр** (Профиль → Админ-панель; на телефоне — выезжающее меню, на компьютере — боковое): Главная, Аналитика, Пользователи (+профиль с таймлайном и действиями), Активность, Генерации, Контент (+FAQ, популярные работы), Категории, Шаблоны, Тренды, Платежи (+способы оплаты), Выручка, Токены (+пакеты, бонус), Подписки, Реферальная система, Маркетинг (+генератор ссылок), Ошибки и журналы, AI-провайдеры (+модели), Система, Настройки (+журнал действий, экспорт CSV).

## Что реально работает, а что нет

| Функция | Статус |
|---|---|
| Все цифры админки — из базы (SQL-агрегации, пагинация, индексы); нет данных → 0 или «Нет данных» | ✅ тесты на реальных данных |
| Регистрация, бонус, токены, возвраты, варианты, блокировка, действия админа с подтверждением и журналом «было → стало» | ✅ тесты |
| Источники и рефералы — только из реального параметра `?start=`; иначе «Не определён» | ✅ тесты |
| Экспорт CSV (UTF-8 с BOM, русские заголовки) | ✅ тесты |
| **Генерация фото и видео** | 🟡 **заглушка** (`AI_MODE=mock`, результат помечен «Тестовый результат»). Реальные AI-провайдеры нужно подключить в `app/ai/external.py` |
| **Telegram Stars** | 🟠 код есть, с реальным Telegram не проверялся |
| **СБП и банковская карта** | ⛔ **не подключены**: нужен платёжный провайдер и ключи. Пользователю не показываются как рабочие; админ может включить показ «Скоро». Таблица платежей уже готова принять любые способы |
| **Подписки** | ⛔ биллинга нет: PRO назначается вручную. «Продления», «истёкшие», «выручка подписок» показывают «Нет данных» |
| Удержание и воронка | накапливаются с момента обновления; для старых пользователей известны только дата регистрации и последний вход |
| Бот, FastAPI, Mini App внутри Telegram | не запускались в среде разработки; интерфейс собран и просмотрен в браузере на данных, созданных через сервисы проекта |

События генераций, платежей и токенов **не дублируются** отдельной таблицей: они считаются из заказов, платежей и журнала токенов. В таблицу событий пишется только то, чего нет в других таблицах (старт бота, открытие Mini App, команды, PRO, действия админов).

## Обновление

Распакуйте архив поверх папки проекта (`.env` и `data/` в нём нет), затем в PowerShell из папки проекта:

```
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\update.ps1
python -m app.main
```

Скрипт удалит устаревшие файлы (`webapp\src\admin\Staff.tsx` и старые экраны), поставит зависимости и соберёт Mini App. База обновится сама при запуске: добавятся новые таблицы и поля, таблица платежей пересоберётся без потери данных, прежние пользователи считаются уже вошедшими и приветствие не увидят.

Новые необязательные настройки: стартовый бонус и число вариантов — «Админка → Токены»; способы оплаты — «Платежи → Способы оплаты»; модели — «AI-провайдеры → AI-модели в интерфейсе».
