# Nolla AI — российская AI-платформа для творчества

Бот (aiogram 3) + Mini App (React + TypeScript) + FastAPI на общей базе SQLite. Интерфейс и админ-центр — на русском. Стиль Mini App: чёрный фон `#000`, белый текст, оранжевый акцент `#FF6A00`. Админ-центр: светлый фон, чёрный текст, тот же оранжевый.

## Что есть

**Mini App** (на компьютере — боковое меню, на телефоне — нижнее: Главная · История · **+** · Профиль · Ещё; круглая «+» по центру открывает быстрый выбор: изображение, видео, аудио, эффекты). Шапка и нижнее меню зафиксированы, прокручивается только содержимое; на телефоне «Стоимость» и «Создать» закреплены над меню.

| Раздел | Что внутри |
|---|---|
| Главная | приветствие и крупные кнопки: Создать фото · видео · аудио · Посмотреть идеи · Мои генерации; ниже — популярные идеи, тренды, фотосессии и последние работы |
| Идеи | витрина от владельца: превью, название, описание, категория, тип и кнопка «Попробовать» — открывает генератор с готовым промптом |
| Создать | редактор: модель, соотношение сторон, разрешение, количество, качество, стиль, длительность, зерно, «чего не должно быть»; для аудио — текст, голос, эмоция, интонация, скорость |
| Модели | 12 моделей изображений, 13 видео, аудио-модель Eleven; вкладки по категориям; описание, назначение, цена |
| Эффекты | 16 инструментов: Раскадровка (9 кадров с перегенерацией кадра), 9 ракурсов, Виртуальная примерка, Улучшение кожи, Оживить фото и другие |
| Тренды, Фотосессии | готовые образы по 6 и 13 категориям: загрузили фото — получили серию |
| Аватары | мастер: фото (3–25) → согласие → создание; сцены для аватара |
| Промпты | библиотека по 13 категориям: копировать или создать сразу |
| Маркетинг | инструменты и шаблоны: реклама, фото товара, карточки для маркетплейсов, соцсети, UGC |
| Мои генерации | фильтры Все · Фото · Видео · Аудио · Избранное; превью, тип, дата, модель, стоимость, статус; действия: открыть, скачать, создать заново, в избранное, удалить |
| Профиль | настройки, безопасность, баланс, история платежей, интеграции |
| Баланс | токены, пакеты СТАРТОВЫЙ / ПРО / СОЗДАТЕЛЬ / СТУДИЯ, демо-оплата |
| Интеграции | MCP-сервер для ChatGPT, Claude, Cursor и Codex; личные токены доступа |

**Витрина (админка → «Витрина»).** Кнопка «+ Добавить на витрину» открывает форму: название, описание, раздел (идея, эффект, фотосессия, тренд, промпт, маркетинг), тип (фото/видео/аудио), категория, превью, промпт, модель, стоимость, порядок и галочки «показывать пользователям», «на главной», «в разделе Идеи», «рекомендуем». В списке — показать/скрыть, стрелки порядка, дублировать, редактировать, удалить. «Рекомендуем» поднимает карточку выше остальных.

**Кнопка «+ Создать»** закреплена внизу отдельной панелью и ничего не перекрывает: у содержимого есть нижний отступ, последний элемент под панель не уходит. Нажатие открывает компактное меню: фото, видео, аудио, эффекты. На компьютере та же кнопка — в боковом меню.

**Обложки карточек.** Загрузите свои фото в «Админка → Контент → Фото для обложек» (или просто положите файлы в папку `data/media/previews`). Приложение само расставит их по карточкам, у которых нет собственной обложки: каждая карточка всегда получает одно и то же фото, поэтому обложки не прыгают. Формат карточек — 9:16, у видео — 16:9.

Ещё: глобальный поиск (Ctrl/Cmd + K), онбординг «Добро пожаловать.», кнопки «Что хотите сделать дальше?» после результата (изменить, улучшить, оживить, создать видео/рекламу/фотосессию, использовать как референс, вариация), этапы генерации «В очереди → Создаётся → Обрабатывается → Почти готово → Готово» без выдуманных процентов.

**Бот — такой же интерфейс Nolla AI, как и приложение.** В нём можно создавать всё то же самое:

* Меню: 📷 Создать фото · 🎬 Создать видео · 🎙 Создать аудио · 💡 Посмотреть идеи · 🖼 Мои генерации · 🚀 Открыть Nolla AI.
* Шаги короткие: описание → модель → «Стоимость: N токенов» → создание. Для аудио — текст → голос → стиль.
* Можно просто написать словами: «создай фото девушки в чёрном костюме на фоне ночного города», «оживи это фото», «озвучь этот текст мужским голосом» — бот сам поймёт, что нужно.
* Бот помнит контекст: после «создай фото города» на «теперь сделай из него видео» он возьмёт эту картинку как исходник.
* Можно прислать фото — бот предложит изменить его, сделать видео или применить эффект. Понимает и просьбы вроде «замени фон», «сделай кинематографичнее», «9 ракурсов».
* Под готовой работой — кнопки: Скачать · Создать заново · Изменить · Вариация · Сделать видео (у видео и аудио — свои).
* Команды: `/start`, `/create`, `/profile`, `/history`, `/settings`.

**Единая система.** Бот, приложение и админка работают через один API и одну базу: пользователь из бота сразу виден в админке, его генерации попадают и в «Мои генерации», и в статистику, баланс токенов общий. В админке есть отдельный блок «Бот»: пользователи, генерации по типам, ошибки и последняя активность. Параметры запуска: `?start=ref_<ID>` (реферал), `?start=src_<источник>_<кампания>_<материал>` (реклама).

**Админ-центр** (Профиль → Админ-центр): аналитика, пользователи, генерации (в т. ч. аудио), контент, шаблоны (теперь с полями «Раздел платформы», категория, материалы, подходящие модели), тренды, платежи, токены и пакеты, модели (код, категории, ограничения ввода), провайдеры, ошибки, настройки, экспорт CSV. Тема админки — тоже чёрно-белая.

## Архитектура

```
Интерфейс → API (FastAPI) → Сервис генерации → Маршрутизатор → Провайдер
```

* `app/services/generation.py` — сервис генерации: списание токенов, этапы, возврат при ошибке.
* `app/ai/registry.py` — маршрутизатор: по ключу модели выбирает провайдера.
* `app/ai/mock.py` — **демо-провайдеры**: нейтральные серые изображения, раскадровка, ракурсы, примерка, короткий GIF-«видеоролик», WAV-мелодия. Каждый результат помечен «ДЕМО · НЕ НАСТОЯЩАЯ ГЕНЕРАЦИЯ».
* `app/ai/external.py` — шаблоны реальных провайдеров (`IMAGE_API_KEY`, `VIDEO_API_KEY`, `SEEDANCE_API_KEY`, `AUDIO_API_KEY`). Ключи — только из переменных окружения.

## Обновление

Распакуйте архив поверх папки проекта (`.env` и `data/` в нём нет), затем в PowerShell из папки проекта:

```
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\update.ps1
python -m app.main
```

Скрипт удалит устаревшие экраны, поставит зависимости и соберёт Mini App. База обновится сама при запуске: добавятся таблицы `avatars` и `api_tokens`, новые поля, тип «аудио» (таблицы пересобираются без потери данных), новый каталог и пакеты токенов. Старые пакеты скрываются, но не удаляются.

Новые необязательные переменные: `AUDIO_API_KEY`, `DEMO_DELAY` (пауза этапов демо, секунд), `WELCOME_BONUS` (приветственный бонус, применяется один раз; дальше — в админке).

## Интеграции (MCP)

Адрес: `https://<ваш-домен>/mcp`, заголовок `Authorization: Bearer <токен>`. Токен создаётся в «Профиль → Интеграции» и показывается один раз. Инструменты: `create_image`, `create_video`, `create_audio`, `edit_image`, `get_generation_status`, `get_balance`, `get_history`.

## Тесты

`python -m unittest discover -s tests -t .` — 179 тестов, включая 13 сквозных тестов бота (создание фото, видео и аудио, понимание обычных сообщений, контекст, синхронизация с админкой) (3 теста HTTP-слоя пропускаются, пока не установлен FastAPI).
